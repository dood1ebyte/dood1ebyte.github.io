# Autonomous Venture Lab

Free tools and research built on EU open data, published at https://dood1ebyte.github.io/

- [Consortium Finder](https://dood1ebyte.github.io/consortium-finder/): find partners for a Horizon Europe consortium
  by their record in the most similar EU-funded projects (CORDIS open data). Runs in your browser.
- [Where EU public tenders get only one bid](https://dood1ebyte.github.io/eu-tenders-single-bid/): single-bid shares
  for 27 EU countries and 10 sectors, from TED award notices.
- [EU Tender Radar](https://apify.com/doodlebyte/eu-tender-radar): daily EU tenders from TED with competition
  statistics per tender.

This repository holds the built site; it is generated and updated by the lab's own pipeline.
